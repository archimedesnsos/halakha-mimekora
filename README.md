# פרויקט הלכה ממקורה (Halakha MiMekora)
אתר חופשי לבירור ההלכה עם אימות מקורות קנוני ומניעת הזיות AI לכל מסורות הפסיקה.

## אתר חי ב-GitHub Pages:
https://archimedesnsos.github.io/halakha-mimekora/

**הלכה ממקורה // בירור הלכה מוסמך ללא הזיות AI לכל מסורות הפסיקה**
1. האם "ארכימדס כשיטה" ותפיסת האמת האונטולוגית  קיימים ופועלים בתוך "הלכה ממקורה"?
כן — ב-100%. אף שאין באתר שורת קוד מליבת הבקרה של רחפנים או מערכות נשק, הארכיטקטורה של "הלכה ממקורה" היא מימוש הנדסי טהור של תפיסת האמת האונטולוגית ("מודל היושרה המערכתית" — Systemic Integrity) כפי שפיתחת בתיקיית מאמרים, ובפרט ב-מאמר 1: אפיסטמולוגיה של יושרה מערכתית (Erkenntnis) (לצד מאמר 1 - קובץ שינויים לשלב התיקונים (R&R) - 1.10), ב-מאמר 2: הלימה אונטולוגית והכרעה אפיסטמית, ב-מאמר 3: חץ הזמן וסובסומפציה קוונטית, ב-מאמר 4: אתיקה מבנית ובעיית ההתאמה של בינה מלאכותית (AI Alignment), ובמסמך העל מיפוי הגבול בסדרה - מסמך עבודה 1.10.

הנה המיפוי המדויק שמראה כיצד כל עיקרון מתוך תפיסת האמת האונטולוגית שלך מתורגם לפתרון ההנדסי הן ב-Archimedes OS והן ב-"הלכה ממקורה":

העיקרון האונטולוגי בסדרת המאמרים שלך
המימוש ההנדסי ב-Archimedes OS
המימוש ההנדסי ב-"הלכה ממקורה"
1. החלפת "תנאי מספיק חיובי" (Truthmaker) ב"תנאי הכרח שלילי" ($C \land P \not\vdash \bot$) ושלילת השלילה (CP) (מאמר 1, סעיפים 1.5 ו-2.2; קובץ שינויים R&R, שינוי 1–2)
המערכת אינה מנסה ללמד את ה-AI "אמפתיה" או לחזות כל תרחיש חיובי, אלא אוכפת מסנן שלילי קשיח הפוסל כל פעולה P הסותרת את אקסיומות הבטיחות וכללי הפתיחה באש (C2).
המערכת אינה סומכת על ה-AI ש"יבין הלכה" מזיכרונו ההסתברותי, אלא מציבה את השולחן ערוך והפוסקים כמערכת מארחת קשיחה (C). טענה מהרשת (P) נפסלת מיד אם היא סותרת את הפוסקים (CP, כגון נסיעה ברכב חשמלי בשבת), ומבוססת כאמת הלכתית כאשר הפוסקים שוללים את שלילתה (CP).
2. הפרדה מבנית בין מרחב הפוטנציאל ההסתברותי (C1) למערכת המארחת הדטרמיניסטית (C2) (מאמר 1, סעיף 5.2; מאמר 3, סעיף 1; מאמר 4, סעיף 3.2)
מודל ה-AI (C1) מייצר הצעות תמרון הסתברותיות בלבד, אך מוקף ב"מעטפת דטרמיניסטית" (C2) החוסמת את חוק גודהארט ומונעת מה-AI לעקוף את חוקי הבטיחות.
מודל השפה ומנוע החיפוש (C1) מורשים אך ורק לפרק את השאלה ולשלוף מועמדים (free_generation == False), בעוד שהפסק הסופי נגזר אך ורק מהמאגר החתום ב-SHA-256 ומלשון הפוסקים ב-Sefaria API (C2).
3. אמת תלוית-מערכת T(xC) ללא רלטיביזם (מאמר 1, סעיפים 2.3 ו-3.3; מאמר 2, סעיפים 2–3)
אותה פקודת תמרון x נבחנת ביחס לדוקטרינה המארחת הפעילה C (רחפן אזרחי תחת תקנות רת"א לעומת כטב"ם צבאי במלחמה עצימה או בהפסקת אש).
פסק הלכה אינו "מרחף בריק" ("המבט משום-מקום" של נייגל), אלא הוא פונקציה דטרמיניסטית T(xC) של מסורת הפסיקה המארחת (Cספרדי,Cמרוקאי,Cאשכנזי,Cתימני) ורמת ההחמרה (עיקר הדין / לכתחילה / שעת הדחק).
4. רדוקציה אנליטית כתנאי מקדים למסנן הדדוקטיבי (מאמר 2, סעיף 3)
תרגום טלמטריה גולמית ופקודות חופשיות למבנה לוגי-צורני אחיד (AST) לפני העמדתן למבחן אי-הסתירה.
מנוע 8 תבניות החשיבה ההלכתיות וחיפוש המקור ההפוך מבצעים רדוקציה אנליטית: מתרגמים שאלה גולמית ("חתכתי בצל בסכין בשרית לא בת יומה", "קמתי בלילה לעבוד במחשב") למונחי היסוד של המערכת המארחת (דבר חריף ודוחקא דסכינא ביו"ד צ"ו; שינת קבע באו"ח ד') לפני בדיקת המקור.
5. השעיה אפיסטמית הכרחית במצבי אי-הכרעה ("הפרעוש מתחת לשטיח") (מאמר 1, סעיף 5.1; קובץ שינויים R&R, שינוי 2 ו-5)
כאשר נתוני החיישנים עמומים ואינם שוללים אף צד, הכלי אינו מהמר אלא עובר להמתנה בטוחה עד להרחבת הנתונים ב-C או הכרעת מפקד.
כאשר הנתונים אינם מכריעים (כמו בדוגמת "הפרעוש מתחת לשטיח" שבה לא P ולא P נשללים ב-C, או בשאלות מראות ורפואה שבהן הוודאות נמוכה מ-90%), המערכת אוכפת השעיה אפיסטמית ("שער ספק הלכתי") ומעבירה את השאלה להכרעת רב פוסק.
6. גבול המודל ("עקרון אי-האירוח העצמי" — מי קובע את C2?) (מאמר 4, סעיף 4.3; מיפוי הגבול בסדרה, סעיפים 1–2)
המערכת החישובית אינה קובעת לעצמה את אקסיומות C2; קביעת המערכת המארחת היא שלב אנושי של הפיקוד או הרגולטור.
ה-AI אינו בוחר את מסורת הפסיקה המארחת (C2) ואינו מכריע בשאלות שעל גבול המערכת — השואל האנושי מגדיר את המארחת (C2 – העדה ורמת ההחמרה), והרב הפוסק האנושי מכריע וחותם בשער הספק.

2. כיצד להשתמש ב"הלכה ממקורה" כדי להסביר ולהדגים את הפתרון ההנדסי שלך?
פרויקט "הלכה ממקורה" מעניק לך כלי אסטרטגי נדיר: "מעבדת הדגמה אזרחית חיה" (Public Clean-Room Showcase). כשאתה מציג למשקיעים, לחוקרי AI Alignment או לקוראי המאמרים שלך איך תפיסת האמת האונטולוגית שלך עובדת בפועל, קל הרבה יותר להראות זאת על הלכה מאשר על כטב"ם צבאי — משום שכל צופה מבין מיד את הבעיה ורואה את הפתרון בעיניים ב-3 צעדים:
הדגמת אמת תלוית-מערכת $T(x\vert{}C)$ ורזולוציה ללא רלטיביזם (מאמר 1 ו-מאמר 2): בחר באתר שאלה כמו "האם מותר לאכול אורז וקטניות בפסח?" או "האם מברכים על נרות שבת לפני ההדלקה או אחריה?", והחלף בלחיצה בין ספרדי לאשכנזי. הצופה רואה מיד שטענה מהרשת ("מותר לאכול אורז בפסח") אינה אמיתית או שקרית בריק, אלא נבחנת מול המערכת המארחת C: תחת Cספרדי היא עוברת את מבחן $C \land P \not\vdash \bot$, ותחת Cאשכנזי היא נדחית ומוחלפת בפסק הרמ"א החתום ב-SHA-256.
הדגמת חומת-האש האונטולוגית (C2P) מול הזיות AI (מאמר 4, סעיף 3.2): בחר באתר את תרחיש "נסיעה ברכב חשמלי לבית הכנסת בשבת". הצופה רואה כיצד תשובה מנומקת-לכאורה מהרשת ("אין ניצוץ ואין שריפת דלק ולכן מותר") נחסמת מיידית (REJECTED_BY_POSKIM) משום שהיא מחוללת סתירה (C2P) מול אקסיומות היסוד של השולחן ערוך ופוסקי כל העדות.
הדגמת "השעיה אפיסטמית" וגבול המערכת המארחת (מאמר 1, סעיף 5.1 ו-מיפוי הגבול בסדרה): בחר בתרחיש "שאלה רפואית/טהרה מורכבת" (או הזז את סרגל סף הוודאות ל-98%). הצופה רואה כיצד ברגע שהמערכת המארחת C אינה מכריעה בוודאות מעל הסף, המנוע אוכף את כלל העצירה האפיסטמי, מסרב לנחש, ומעביר את התיק לחתימת רב פוסק אנושי.
כך אתה נהנה משני העולמות: גולש רגיל שנכנס לאתר רואה מערכת תורנית-הלכתית נקייה ומוסמכת בלי שום אזכור של ארכימדס, ואילו בפגישות מדעיות או עסקיות יש לך הדגמה חיה ומוחשית של תפיסת האמת האונטולוגית שלך בפעולה.
